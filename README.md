# td-scraping-to-kpi

## Tableau de bord

[Ouvrir le dashboard](https://affes-bi.github.io/td-scraping-to-kpi/)

Ce tableau de bord affiche un indicateur calculé à partir de 12 offres d'emploi : le pourcentage d'offres qui mentionnent la compétence « AI », ainsi que les compétences les plus citées. Les compétences sont extraites des textes d'offres par un modèle local (Ollama, `qwen3:8b`).
